      About

      This page runs the deep-research-agent library on the sources you give it. The agent plans queries (always including one looking for contrary evidence), searches your sources, reads them, merges republished copies, pulls out claims, matches claims across sources and checks every quote against the text it was read from.

      disputed
      Sources give figures more than the tolerance apart, or one says a thing is and another says it is not. Both sides are shown; no winner is picked.
      well-corroborated
      Three or more independent sources agree.
      corroborated
      Two independent sources agree.
      single-source
      Only one source says it.
      quote verified
      The quoted sentence was found in the text of that source. A claim whose quote is not found is dropped and counted.

      Copies of the same story count once: the copy from the most authoritative domain represents the group. Authority is a coarse prior from the domain (research, official, press, reference, industry, commercial, user-generated, unknown); it orders sources, it does not make a claim true.

      Claims are found by sentence patterns such as "X was 8.2 percent" or "X is not Y", so prose that states a number another way is not picked up. Search runs over the sources you supply; it does not search the web.
